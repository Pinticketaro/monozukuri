# 案を分ける（ブランチ）

2つ以上の案を並べて試したいとき（「ファンを外と内の両方で見たい」など）は、同じ版から案を分ける。
- 名前は版の番号に英小文字を付ける：`v03` から `v04a`・`v04b`。パラメータファイルを `params_v04a.json`・`params_v04b.json` として作り、どちらも `meta.parent` に分けた元（`"v03"`）を書く。
- それぞれ mock → レンダリング → `build_page.py`（manifest の `prev` は分けた元の `v03`）。ページでは同じ番号の案が点線の枠でまとまり、「別の案」から行き来できる。
- ページの版のボタンの下に「バージョン履歴を見る」があり、開くと版のつながり（どの版から作ったか）がツリーで出る。続けなかった案は薄い点線になる。つながりは manifest の `prev` で決まるので、分けた案と、選んだ案から続けた版では必ず `prev` を書く。
- 案どうしを比べる図は、片方の版の manifest の `compare` に `{"before": "out/v04a/preview.png", "after": "out/v04b/preview.png", "caption": "A案と B案"}` で入れる。
- 「どちらの案にしますか」を options の問いにして選んでもらう（案の画像を `img` に付けると選びやすい）。
- 選んだ案から続けるときは、次の版（`v05`）の `meta.parent` にその案（`"v04b"`）を書く。選ばなかった案は消さずに残し、決定事項に「v04b を採用（理由）」と書く。
