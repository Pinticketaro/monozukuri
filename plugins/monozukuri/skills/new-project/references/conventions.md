# モックの作り方と版の回し方

## モックの細かさ
モックは「形・大きさ・比率・配置」を見て決めるためのもの。次のものは作らない（モデル化で人が決める）：
フィレットや面取りの細部、ネジ山、継ぎ目の凹凸、公差、印刷の向きのための工夫、文字や模様の正確な形。
代わりに、見た目と干渉の判断に効くものは入れる：中に入れる物の大きさ（中身のブロック）、ネジの頭、キーキャップ・ボタンなど上に出る物、透ける素材の不透明度。

## 4つの関所
モック（形・比率）→ 試し片（この機械・この材料の値）→ 部分試作（実物部品との取り合い）→ 本番。
関所ごとの確認項目は雛形の `docs/チェックリスト.md`、根拠は `fab-requirements.md`。

## 寸法ファイル（params/params_vNN.json）
- 1つの版の数値はここだけに書く。`tools/mock.py` には数値を直接書かず、`P.項目名` で読む。
- 項目ごとに `value`・`unit`・`label`（人が読む名前）を付ける。label は寸法表と確認ページの「寸法の変化」にそのまま出る。
- 色は `meta.colors` にまとめる（版で色を比べるときに変えやすい）。
- 加工の値は `fab` に分け、各項目に `status`（初期値／実測／指針／規格／計算）と `basis`（根拠）を書く。モックとモデル化はどちらも `P.t_top` のように同じ名前で使う。
- 試し片で測ったら、値・status・basis（測った日と条件）を書き換えて版を上げる。測定の生データは `measurements/試し片記録.csv`。
- 新しい版は、前の版のファイルをコピーして版番号を上げ、変える値だけを書き換える。

## mock.py の書き方
- `build(prm)` が `(部品名, 形, 色, 不透明度)` の並びと、注意点（notes）を返す。
- 形は manifold3d：輪郭（shapely で作った点の並び）を押し出す `slab()`、円柱 `cyl()`、ブール演算（`+` 足す、`-` 引く、`^` 重なり）、`translate()`。
- 透けるもの（アクリルなど）は不透明度 0.5〜0.75。中身は暗い色にすると外側との関係が見やすい。
- 「中身が枠より大きい」「造形範囲を超える」など、寸法から機械的にわかる問題は notes に入れる（確認ページと寸法表に出る）。
- 部品の向きは README の原点・向きに合わせる（既定は外形の中心が X=0・Y=0、底面 Z=0、Z が上）。

## 版の回し方
1. 前の版のフィードバックを読む（review-page スキル）
2. 寸法ファイルを1つ上の版としてコピーして、変える値だけ書き換える。1つの版で変える条件はなるべく1つ
3. モック → 外観・平面図・断面 → 前の版との比較 → 寸法の差分
4. 確認ページに載せ、反映したフィードバックを閉じる
5. LOG.md に「何を変えた → どう見えた → 次に何を試す」を書く。コミットメッセージも同じ形

## 画像の名前
`out/vNN/preview.png`（外観）、`plan.png`（平面図）、`section.png`（断面）、`compare.png`（比較）、`model.glb`（回して見る用）。
前の版の画像は上書きしない（比較に使う）。

## 単位の関所
モデルを読み込んだら、既知の寸法を1つ確かめる。`render_model.py` は全体の大きさを mm で表示し、5mm 未満・2000mm 超なら単位の取り違え（25.4倍・1000倍）を警告する。STEP は cascadio 経由でメートルになるが、スクリプト側で mm にそろえている。

## 引き継ぎ（モデル化へ）
形が固まったら `tools/dims_sheet.py vNN` で寸法表と Fusion 用のパラメータ一覧（`docs/fusion_params_vNN.csv`）を作り、`docs/引き継ぎ.md` の手順で渡す。モデル化の結果（STL / STEP）は `out/vNN/model/` に置き、確認ページに「モデル（Fusion）」の版として載せてモックと比べる。
