# デジタルファブリケーションの技術要件（要約）

出典つきの全文は `fab-research-report.md`。ここは判断に使う要点だけ。区分：【実測】出典が測った値／【指針】メーカー・加工サービス・大学ラボの推奨／【規格】JIS・ISO／【経験則】測定の裏付けなし／【計算】ほかの値から算出。

## 0. いちばん大事な考え方
- 公開されている数値は**初期値**。出典どうしのずれが「圧入」と「ガタ」の差と同じくらいある（3mmアクリルのカーフ 0.125【実測】と 0.18【指針】、FDMの圧入クリアランス 0〜0.05 と 0.2【指針】）。
- だから値は「初期値＋信頼度＋測り方」で持ち、**テストピースで自分の機材の値を測って寸法ファイル（fab）とCADのユーザーパラメータに戻す**。雛形では `tools/coupons.py` → `measurements/試し片記録.csv` → `params` の `fab`（status を「実測」に）→ `docs/fusion_params_vNN.csv`。
- 他人の機械・他の材料・他の設定で決めた値は持ち込まない。条件（機械・材料・実板厚・出力・速度・パス数・焦点）が1つ変わったら測り直す。

## 1. 4つの関所（推論。Fab Academy・大学ラボの共通手順から）
| 関所 | 作るもの | 答える問い |
|---|---|---|
| モック | 粗い立体・レンダー・段ボール | 大きさ・比率・配置・見た目 |
| テストピース | カーフ四角・スロットのコーム・はめあい片・インサート穴片 | この機械・この材料の値 |
| 部分試作 | ケースの一角（USB切り欠き・ネジボス1つ・中身の角） | 実物部品との取り合い |
| 本番 | 全体 | — |
モックのメッシュは参照用の下敷きにだけ使い、Fusion では描き直す（STL は非可逆。STEP が編集向き【指針：CadQuery】）。

## 2. レーザー加工
| 項目 | 初期値・規則 | 区分 | 測り方・注意 |
|---|---|---|---|
| カーフ k（定義：カーフの**全幅**。オフセットは k/2） | CO2・3mmアクリル 0.125〜0.18、合板3mm 0.20、MDF3mm 0.16、10〜12mmで約0.3 | 実測／指針 | 20mm角をカットし k＝20−実測。X・Y別に。出典で「全幅／片側」の書き方が混在するので定義を固定する |
| ダイオードのカーフ | 0.05（1件）〜0.1〜0.5 | 実測／経験則（信頼度低） | 必ず実測。X/Yで0.05〜0.10違うことがある |
| 補正 | 閉じた輪郭を k/2 ずらす（外形は外、穴は内）。LightBurn の Kerf Offset には k/2 | 経験則 | 補正するかしないか、どちらか一方に決める |
| スロットのはめあい | 最適幅は機械ごと（MIT：板厚−0.10〜0.15、Kamakura：板厚−0.3〜0.5） | 実測 | 持ち運べない値。板厚±0.20を0.05刻み9本のコームで決める |
| アクリルの圧入 | しない。すきまばめ＋ネジか接着 | 推論 | 締め付けで内角から割れる。内角R 0.5mm以上【経験則：Ponoko】 |
| 線どうしの間隔 | 0.5mm以上（未満は焼け落ちる）。細部は1mm以上。カットアウト幅は板厚以上 | 指針 | — |
| 板厚 | キャスト±15%、押出±5%（Trotec）。3mmで±0.7mm（ミスミ） | 指針 | シートごとに4隅と中央を実測。呼び寸法で設計しない |
| アクリルの選び方 | 彫刻・ネジ穴が多い → キャスト。板厚の揃いが大事なカット部品 → 押出（周波数5kHz以下） | 指針＋推論 | — |
| 条件出し | 板厚を測る → 出力・速度のグリッド → きれいに抜ける最速 → カーフ → コーム → 小組立 → 本番 | 推論 | 6mm超は焦点を板厚の約1/3へ（Trotec）。遅すぎる速度は火災の危険 |
| データ | DXF（R14）か SVG、単位 mm。閉じたパス、重複線なし、文字はパス化、ページ内に置く。色＝加工条件。内側→外形の順 | 指針（SendCutSend）／経験則 | 読み込んだら一番大きい輪郭の寸法で縮尺を確認 |
| 加工範囲 | 例：xTool P2 600×305、Glowforge Pro 495×297 | 指針 | 余白を足して入らなければ分割 |

## 3. FDM 3Dプリント
| 項目 | 初期値・規則 | 区分 | 測り方・注意 |
|---|---|---|---|
| クリアランス（片側） | 一般0.2・着脱0.3・可動0.4以上（Ultimaker S7 の表）／高精度機は0〜0.05 | 指針 | Ender-3 の値は出典なし。±0.1の3段のテストピースで決める（QIDI の方法） |
| 穴の縮み | 垂直穴は小さく出る。CAD で +0.2（4mm穴を4.2mm）か、スライサーの穴補正 | 経験則／指針 | **どちらか一方だけ**。Bambu の穴補正は記事内で符号が矛盾するので1回印刷して向きを確認 |
| 形の限界 | オーバーハング45°、ブリッジ5mm、壁はノズル径の2倍以上（0.4→0.8mm）、φ5未満のピンは弱い | 指針 | メーカーTDSの55〜70°・30〜40mmは最良条件の値。Ender-3 は45°/5mmで設計 |
| ベッド面の縁 | 45°の面取り（エレファントフットと反りを減らす）。水平のネジ穴はティアドロップ形 | 指針 | — |
| 強度 | Z方向はXYの84〜90%（PLA 39/35MPa）。荷重は層に沿わせる。外周を増やすほうがインフィルを増やすより強くなる | 実測 | — |
| ヒートインサート（M3） | 下穴4.0（CNC Kitchen・ruthex）／約4.3（UW）、深さ＝長さ＋1、最小壁1.6、外周4本・インフィル25%以上 | 指針 | 4.0〜4.4のテストピースで決める。こては印刷温度＋10〜20℃から |
| インサート（M2・M2.5・M4） | 下穴 3.2・4.0・5.6、最小壁 1.3・1.6・2.1 | 指針 | ボス外径＝穴径＋2×最小壁 |
| 材料 | PLA：HDT 57℃・Tg 60℃。ASA：HDT 100℃。ABS/ASA は筐体が要る | 実測／指針 | 車内・窓際は PLA 不可。筐体のない Ender-3 の大きく平たい部品は PLA か PETG |
| 大きい部品 | 造形範囲を超えたら分割 | — | 継ぎ手の寸法の出典はない。部分試作で継ぎ目を確かめる |

## 4. データ形式と単位
| 受け渡し | 形式 | 注意 |
|---|---|---|
| モック → Fusion | OBJ / STL を参照用に | 描き直す |
| Fusion → スライサー | 3MF（単位と設定を持てる）。STL なら寸法を確認 | STL は単位なし |
| Fusion → レーザー | スケッチから DXF、または SVG（mm） | 色＝条件 |
| CAD間・保管 | STEP | 単位を持つが、読む側が尊重するかはツール次第。cascadio 経由ではメートルになる |
- **単位の関所**：読み込むたびに既知の寸法を1つ測る。25.4倍（インチ）・1000倍（m）・1.067倍／1.333倍（px の解像度違い）を止める。`render_model.py` は全体の大きさを mm で表示し、不自然なら警告する。
- Inkscape：ドキュメント単位を mm に（表示単位とは別）。DXF は「名前を付けて保存」→ R14、基本単位を明示【指針：SendCutSend】。96/90 px/in の違い、DXF の $INSUNITS、Blender の単位スケールは【未検証】。

## 5. パラメトリック設計と版管理
- Fusion：名前付きユーザーパラメータ、スケッチは完全拘束（色表示を当てにしない）、1フィーチャー1スケッチ、部品ごとにコンポーネント、編集中のコンポーネントをアクティブに、**寸法を変えて追従するかのフレックステスト**【指針：ACE Makerspace・Autodesk】。正接拘束は寸法変更で反転することがある。
- 最低限のパラメータ：実板厚 `t_*`、`kerf`、`clr_fit`／`clr_slide`、`insert_hole`、壁厚。テストピースの記録から転記する。
- コードCAD（CadQuery・build123d）は格子とパラメータで決まる平面形状（プレートなど）に向く。FreeCAD 1.0 のトポロジカルネーミング問題は完全には解決していない。
- Git：テキスト（寸法ファイル・SVG/DXF・記録・スクリプト）は普通に、.f3d・.blend・STEP・大きい STL/3MF は Git LFS。GitHub は STL を 10MB まで3D表示。加工に送るたびにタグ（例 `v03-plate-kerf0.15`）。
- 測定の記録：同じ位置で3回以上、ばらつきも。データシートがある部品はネジ径ではなくメーカー推奨値から寸法を取る。

| USB-C 切り欠き | ケーブル側オーバーモールドの幅 12.35mm（仕様準拠のフットプリント）。高さ6.5mmは未確認。いちばん太いケーブルで試す | 指針／未検証 |

## 7. 自分の機材で測って決める値（チェック用）
機械・材料・設定ごとのカーフ（X/Y）、シートごとの実板厚、コームの最適幅、FDM のクリアランス（一般・着脱・圧入）、穴補正量（CADかスライサーの一方）、インサート下穴径とこて温度、カット条件、フォームの実厚と圧縮量、USB-C ケーブルの実寸。

## 8. 一次資料で確かめられなかった値（未検証として扱う）
ダイオードレーザー用保護メガネのOD値（オープンフレームのダイオード機を使うなら最優先で確認）、Ender-3 固有の公差、POM・フォームのカーフ、分割の継ぎ手寸法、キーボードのガスケット圧縮量、M3ナットトラップ（対辺5.5＋0.2〜0.3）、タッピング下穴2.5〜2.8、PCB下の逃げ1〜2mm。
