# 安全：レーザーカットしてよい材料・いけない材料

ラボや出典によって判断が分かれる材料がある。**「全面禁止」は常に止め、「ラボ次第」は所属ラボ（使う機械）のリストで許可を確かめてから**にする。材料は SDS かリサイクルコード（「3」・PVC・V の表示は塩ビ）で特定し、見た目で判断しない。詳細と出典は `fab-research-report.md` の「安全」。

## 全面禁止
| 材料 | 理由 | 出典 |
|---|---|---|
| PVC・塩素系全般（ビニール、合成皮革、塩ビ発泡板、Kydex） | 塩素・塩化水素が出て、体と機械（レンズ・ミラー・金属部）を傷める。換気では解決しない | UW Fab Lab、Thunder Laser |
| ポリカーボネート | カットしきれずに溶け、変色・発火する | UW |
| ABS | シアン化物ガス、溶けて発火 | UW |
| HDPE | 溶けて発火 | UW |
| PTFE（テフロン） | フィルターで除去できない有害ガス | UW |
| ガラス繊維、コート付き炭素繊維 | 樹脂・コーティングが燃えて有害ガス | UW |
| Br・Cl・F・I を含むもの、C–N 結合を持つもの、難燃と表示されたもの（一般則） | 有毒ガス・火災・機械の損傷 | Bristol Hackspace |
| ポリスチレンフォーム（発泡スチロール）・HIPS | 「レーザー火災の原因の第1位」（UW）。Bristol も禁止 | UW、Bristol |
| 成分がわからないもの | 何が出るかわからない | 各ラボ共通 |

## ラボ次第（許可を確かめてから）
| 材料 | 分かれ方 |
|---|---|
| MDF | UW は禁止（ホルムアルデヒド・光学系）、Bristol は許可 |
| POM（デルリン） | UW は禁止、Bristol は許可 |
| EVA フォーム | Thunder Laser は安全、UW は禁止 |
| **PU フォーム（PORON 系を含む）** | Thunder Laser は安全とするが、C–N 結合を含むので Bristol の一般則では禁止。**キーボードのガスケットで定番の PORON はこれに当たる**。保守側は刃物でカットする（型紙を印刷してカッター） |
| PET / PETG、ナイロン | Bristol は禁止 |
| PP、PLA | 要監視（PP は溶けて発火しうる、PLA は溶けがち） |
| 合板 | 無処理のものだけ（UW）、船舶用合板は不可（Bristol） |

## 運転の決まり
- 窓を開けて扇風機を回すのは排気ではない。筐体からの排気に粒子フィルター＋活性炭。
- 運転中は機械から離れない（エアアシストは炎を煽りうる）。消火器を手の届く所に。
- 誤って PVC をカットしたら、蓋を閉じたまま排気を最大で30分以上回し、その後で光学系を清掃（Thunder Laser）。
- オープンフレームのダイオード機は、波長（445〜455nm）に合った保護メガネが要る。OD値の一次資料は今回の調査で取れていないので、機械のメーカーの指示に従う。

## 3Dプリントの安全・使用上の注意
- PLA は約57℃（HDT）で変形し始める。車内・直射日光・熱を持つ機器の近くは ASA など。
- ABS / ASA は筐体（エンクロージャー）と換気を前提にする。
