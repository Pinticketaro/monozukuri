# 資料

寸法の根拠にした図面・データシート・写真・実測の記録を、このフォルダに置く。
寸法ファイルの各項目の `basis`（根拠）と `ref`（このフォルダのファイル名か URL）から指す。確認ページの「寸法と根拠」と「資料」に出る。

| ファイル | 何か | 出典（URL・ページ） | 取った日 | 使った寸法（キー） |
|---|---|---|---|---|
| | | | | |

- 写真には定規か、大きさのわかる物を一緒に写す
- 出典のファイルを置けないとき（ライセンス・大きすぎる）は、URL とページだけを書く
- 記憶や推測の値は資料にならない。寸法ファイルの basis に「仮（記憶・要確認）」と書いておく
