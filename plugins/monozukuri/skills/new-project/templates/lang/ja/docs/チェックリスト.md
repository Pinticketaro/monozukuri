# チェックリスト（段階ごと）

公開されている数値は初期値。テストピースで自分の機材の値を測ってから本番に進む。
根拠と出典は monozukuri プラグインの「デジタルファブリケーションの技術要件」。
<!-- 作り方（レーザー／3Dプリント）に関係しない項目は、雛形を作るときに外してある -->

## 1. モック
- [ ] 大きさ・比率・配置を確認し、確認ページでフィードバックをもらった
- [ ] 決めたことを `docs/決定事項.md` に理由付きで書いた

## 2. テストピース（`python3 tools/coupons.py`）
<!-- laser -->
レーザー
- [ ] 使うシートの板厚を4隅と中央で実測し、`t_*` を置き換えた
- [ ] 出力・速度を変えて、きれいに抜ける最速の条件を決めた（遅すぎると火災の危険）
- [ ] カーフ四角でカーフ k（全幅）を X・Y 別に測った → `kerf`
- [ ] スロットのコームで、入って抜けない幅を選んだ（本番と同じシートで）
- [ ] 材料を SDS／リサイクルコードで特定し、所属ラボのリストで許可を確かめた（PORON などの PU、MDF、POM、EVA、PETG はラボ次第）
<!-- /laser -->
<!-- fdm -->

3Dプリント（本番と同じフィラメント・設定で）
- [ ] はめあい片で `clr_fit`・`clr_slide` を決めた
- [ ] インサート穴片（4.0〜4.4）で `insert_hole` を決めた
- [ ] 穴の補正は CAD かスライサーの**一方だけ**にした
- [ ] サポートが要る面（`mock.py` の注意に出る）を減らす向き・形を決めた
<!-- /fdm -->

記録
- [ ] `measurements/試し片記録.csv` に3回以上の測定値・選んだ値・反映先を書いた
- [ ] 寸法ファイルの `fab` の値を書き換え、status を「実測」にした

## 3. モデル化（Fusion など）
- [ ] `docs/寸法表_vNN.md` と `docs/fusion_params_vNN.csv` の名前でユーザーパラメータを作った
- [ ] スケッチを完全拘束にし、部品ごとにコンポーネントにした
- [ ] 寸法を変えて追従するか試した（フレックステスト）
- [ ] 取り合い寸法がすべて実測値かデータシートに遡れる
- [ ] 書き出したモデルを確認ページに載せ、全体の大きさ（mm）が既知の寸法と合うことを確かめた（25.4倍・1000倍の取り違えがない）

## 4. 部分試作
- [ ] ケースの一角（USB切り欠き・ネジボス1つ・中身の角）をレーザーカットして／3Dプリントして実物と合わせた
- [ ] USB-C はいちばん太いケーブルが奥まで挿さった

## 5. 本番の前
<!-- laser -->
レーザー
- [ ] 閉じたパス・重複線なし・文字はパス化・ページ内・色と条件の対応・内側からカットする・線の間隔0.5mm以上
- [ ] 加工ソフトで読み込んだら、いちばん大きい輪郭の寸法を確認した
- [ ] アクリルのネジ穴は中心から縁まで穴径の1.5倍以上
<!-- /laser -->
<!-- fdm -->

3Dプリント
- [ ] オーバーハング45°・ブリッジ5mm以内、壁0.8mm以上、ベッド面の縁は面取り、水平のネジ穴はティアドロップ形
- [ ] 造形範囲に入る（入らなければ分割と継ぎ目を部分試作で確認済み）
- [ ] 材料が使う場所の温度に合う（PLA は約57℃で変形）
<!-- /fdm -->

## 6. 組み立て・仕上げ
- [ ] ネジ穴は JIS B 1001 の2〜3級（M3 なら3.4〜3.6）、アクリルにはワッシャー、締めすぎない
- [ ] 板厚・フォームの積み上げをワーストケースで見て、ばらつきをフォームに集めた。圧縮量はボスの高さで決まる
<!-- laser -->
- [ ] アクリルの縁にアルコール・CA接着剤を使っていない
<!-- /laser -->
- [ ] 塗装するなら合わせ面とインサート穴をマスキングし、インサートは塗装後

## 7. 記録
- [ ] 加工に送ったファイル・寸法ファイル・テストピースの記録をコミットし、タグを打った
