# モデル化への引き継ぎ

モックは形と比率を決めるための粗い立体です。製造に使う形（フィレット、継ぎ目、ネジ受け、公差、印刷の向き）は、モデル化で人が決めます。

## 渡すもの
- `docs/寸法表_vNN.md`：寸法の一覧、加工の値（実測か初期値か）、モックで見つかった注意点
- `docs/fusion_params_vNN.csv`：Fusion のユーザーパラメータに写す一覧（名前・値・単位・コメント）
- `docs/チェックリスト.md`：モデル化と本番前の確認項目
- `out/vNN/` の外観・平面図・断面図
- 確認ページのリンク：未対応のフィードバックが残っていないかを確認する
- `docs/決定事項.md`

## モデル化で決めること（モックでは決めない）
- 部品の分け方と継ぎ目の形（プリンタの造形範囲に入るか）
- ネジ・インサート・ナットの受け方
- はめ合いの公差：寸法表の `clr_*`（試し片で実測した値。「初期値」のままなら先に試し片）
- 印刷の向きとサポート、レーザーのカーフ補正（`kerf`、補正するならオフセットは k/2）
- 角の丸み・面取り

## モデル化したら
1. STL か STEP で書き出して `out/vNN/model/` に置く
2. 確認ページに「モデル（Fusion）」の版として載せる。モックとの比較を付ける
3. 寸法がモックと違う所は、寸法ファイルにも反映する（次の検討の出発点がずれないように）
