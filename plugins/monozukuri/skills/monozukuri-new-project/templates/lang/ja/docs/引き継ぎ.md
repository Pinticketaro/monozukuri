# モデル化への引き継ぎ

モックは形と比率を決めるための粗い立体です。製造に使う形（フィレット、分割面、ネジボス、公差、印刷の向き）は、モデル化で人が決めます。

## 渡すもの
- `docs/寸法表_vNN.md`：寸法の一覧、加工パラメータ（実測か初期値か）、モックで見つかった注意点
- `docs/fusion_params_vNN.csv`：Fusion のユーザーパラメータに写す一覧（名前・値・単位・コメント）
- `docs/チェックリスト.md`：モデル化と本番前の確認項目
- `out/vNN/` の外観・平面図・断面図
- 確認ページのリンク：未対応のフィードバックが残っていないかを確認する
- `docs/決定事項.md`
- `out/vNN/step/assembly_vNN.step`：モックの形をソリッドにしたもの（CadQuery があるとき）。Fusion で開くと部品ごとのコンポーネントになり、角丸・穴は本物の円弧・円柱なので、そのまま押し出しやフィレットを足せる。寸法の数値は fusion_params の値と同じ

モックの STEP はあくまで出発点です。分割面・ネジボス・公差などは入っていないので、パラメータ（fusion_params）で組み直すか、STEP に足していくかは作る人が決めます。

- 部品の分け方と分割面の形（プリンターの造形範囲に入るか）
- ネジ・インサート・ナットの受け方
- はめ合いの公差：寸法表の `clr_*`（テストピースで実測した値。「初期値」のままなら先にテストピース）

- 印刷の向きとサポート（`mock.py` の注意に、サポートが要りそうな面が出る）

- レーザーのカーフ補正（`kerf`、補正するならオフセットは k/2）

- 角R・面取り

## モデル化したら
1. STL か STEP でエクスポートして `out/vNN/model/` に置く
2. 確認ページに「モデル（Fusion）」の版として載せる。モックとの比較を付ける
3. 寸法がモックと違う所は、パラメータファイルにも反映する（次の検討の出発点がずれないように）
