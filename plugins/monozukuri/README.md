# monozukuri

レーザー加工・3Dプリントのものづくりで、**立体のイメージを作る → 見る → フィードバック → 次の版** を速く回すためのプラグイン。
モックは形と比率を決めるための粗い立体で、最終形は Fusion などで人がモデル化する前提。モデル化した結果も同じ確認ページで見比べられる。

## スキル

| スキル | こう頼むと動く | すること |
|---|---|---|
| setup | 「モックの環境を整えて」 | 描画・断面・比較・加工データに必要なもの（shapely、manifold3d、trimesh、cascadio、cadquery、ezdxf、playwright＋Chromium、three.js、日本語フォント）を入れ、テスト描画まで確かめる |
| new-project | 「新しいものづくりを始めたい」「試し片を作って」 | 寸法ファイル（形の寸法＋加工の値と信頼度）・モック生成（1つの形の定義から STL と STEP）・試し片生成・描画・断面・比較・寸法表のスクリプト、段階チェックリスト、README・LOG・決定事項・引き継ぎ・Git設定の雛形を作り、最初のモックを描く |
| review-page | 「この版の確認ページを作って」「フィードバックを読んで」 | モックや人が作ったモデル（STL/OBJ/STEP）を描画し、前の版と比べ、プロジェクトごとの確認ページ（同じURL）に版を追加して公開。ページに書かれたフィードバックを読み、反映したものを閉じる |
| fab-prep | 「製作前にチェックして」「USBの所だけ先に刷りたい」「加工データを書き出して」 | 製作前チェック（番号の付いた図と NG／注意／確認の表）、部分試作の切り出し（STL・STEP・レーザー用データ）、加工データの書き出し（レーザー SVG/DXF をカーフ補正つきで、3Dプリント 3MF） |
| machines | 「うちの Ender-3 を登録して」「測った値を保存して」「このプロジェクトに機材の値を入れて」 | 機材プロファイル（造形範囲・加工範囲・ノズル径・ラボの材料の決まり・試し片で測った値）を残し、プロジェクトに適用して fab の値を「実測」にする |

## 確認ページでできること
- 版の切り替え（URL の末尾に `#v03` を付けるとその版が開く）
- 外観・平面図・断面図、クリックで拡大
- 前の版との比較スライダー、寸法の変化の表
- 3Dモデルを回して見る（スマホでも）
- 書き出す：見ている版の STL（部品ごと＋全体）か STEP（組み立て＋部品ごと）を ZIP で保存
- 決めてほしいこと：はい／いいえ は切り替え、案はラジオボタンで選ぶだけで答えが残る（1人1件、選び直せる。人数と選んだ人が出る）。Claude が決定を書き込むと「決定：B案」が付く
- フィードバック（直したい／良い／質問）を図や問いごとに書ける。Claude が読み、反映したら「反映済み」と返信を付ける

## 本番の手前（fab-prep）
部品ごとの作り方（laser／fdm／none）・材料・板厚のキーを寸法ファイルの `meta.parts` に書いておくと（人が作ったモデルは scene.json に）、次の3つが使える。
- **製作前チェック**（`fab_check.py`）：材料の安全（全面禁止／ラボ次第、機材に登録したラボの決まり）、板の形か（段差・座ぐり）、板厚の食い違い、加工範囲、穴と縁の距離（アクリル 1.5倍）、ボルト穴の等級（JIS B 1001）、線の間隔 0.5mm・細部 1mm、狭い切り抜き、内角／造形範囲、閉じたメッシュか、壁の薄さ（ノズル径の2倍）、45°を超えるオーバーハング、5mmを超える天井・ブリッジ、材料の耐熱／まだ初期値の加工の値。図に番号付きの印、`--render` で刷る向きの外観に色付け
- **部分試作の切り出し**（`cut_region.py`）：箱・点のまわり・名前付きの範囲で切り出し、STL、元に STEP があれば正確に切った STEP、レーザーの板ならその部分の SVG / DXF
- **加工データの書き出し**（`export_fab.py`）：レーザーは材料・板厚ごとに SVG / DXF（mm、k/2 のカーフ補正、穴 → 外形の順、加工範囲に並べる）と並べた図、3Dプリントは刷る向きの 3MF。加工ソフトで確かめる寸法を `fab.md` に出す

## 機材プロファイル（machines）
1台＝1つの JSON に、造形範囲・加工範囲・ノズル径・ラボの材料の決まりと、試し片で測った値を「機械×材料（×板厚）」ごとに残す。
`apply` でプロジェクトに適用すると、寸法ファイルが1つ上の版になり、合う値が「実測」（根拠に機材・日付・試し片）に置き換わる。製作前チェックと加工データの書き出しは、機材の範囲とノズル径で判定する。

## デジタルファブリケーションの技術要件
new-project スキルの参照資料に、レーザー加工・FDM 3Dプリント・データ形式と単位・パラメトリック設計と版管理・組み立てと仕上げ・材料の安全をまとめてある（出典つきの調査レポートも同梱）。
考え方の中心は「公開されている数値は初期値」。出典どうしのずれが圧入とガタの差ほどあるので、次の流れで自分の機材の値を決める。
1. 4つの関所：モック → 試し片 → 部分試作 → 本番
2. 試し片（`coupons.py`）：レーザーのカーフ四角とスロットのコーム、3Dプリントのはめあい片とインサート穴片
3. 測った値を `measurements/試し片記録.csv` → 寸法ファイルの `fab`（status を「実測」に）→ 寸法表と Fusion 用パラメータ一覧（`fusion_params_vNN.csv`）
4. 読み込むたびの単位の関所（`render_model.py` が全体の大きさを mm で出し、不自然なら警告）

## 必要なもの
- Python 3.10 以上、Node.js（three.js を入れるため）。setup スキルが残りをそろえる。
- 機材プロファイルの置き場は既定で `~/.monozukuri/machines/`（`MONOZUKURI_MACHINES` で変更）。クラウドの作業環境は消えるので、PC のフォルダかリポジトリに置く。
- 外部サービスの接続や環境変数は不要。

## STEP によるモデリング
モックの形は雛形の `tools/geom.py` で書く（角丸の長方形・円・多角形を押し出し、足す・引く・重なり）。同じ定義から
- STL（manifold3d）：描画・断面・確認ページ用
- STEP（CadQuery）：角丸は本物の円弧、穴は本物の円柱。部品ごとの STEP と、部品名・色付きの組み立て STEP（Fusion で開くと部品ごとのコンポーネント）

が出る。書き出した STEP は読み直してメッシュと大きさを照合する。STEP はモデル化の出発点で、継ぎ目・ネジ受け・公差などは人がモデル化で作る。

## スクリプトを直接使うとき
各スキルの `scripts/` にある。どれも `--help` で使い方が出る。
- `render_model.py`：STL/OBJ/3MF/GLB/STEP を影付きで描画（複数の視点を1枚に）、GLB の書き出し
- `slices.py`：平面図（部品の輪郭の重ね合わせ）と断面図
- `compare.py`：前後の画像を並べ、変わった所を赤で強調
- `params_diff.py`：寸法ファイルの差分
- `build_page.py`：確認ページに版を追加
- `scaffold.py`：雛形の作成
- 雛形の `tools/geom.py`：形の定義（STL と STEP の両方に出せる）
- 雛形の `tools/coupons.py`：試し片（レーザー SVG、3Dプリント STL、手順書）
- 雛形の `tools/dims_sheet.py`：寸法表と Fusion 用パラメータ一覧
- `fab_check.py`・`cut_region.py`・`export_fab.py`（fab-prep。雛形の `tools/` にもコピーされる）：製作前チェック・部分試作・加工データ
- `machines.py`（machines）：機材プロファイルの登録・記録・適用
