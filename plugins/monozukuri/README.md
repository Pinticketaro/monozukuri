# monozukuri（詳しい説明）

レーザー加工・3Dプリントのものづくりで、**立体のイメージを作る → 見る → フィードバック → 次の版** を速く回すためのプラグイン。
モックは形と比率を決めるための粗い立体で、最終形は Fusion などで人がモデル化する前提。モデル化した結果も同じ確認ページで見比べられる。

入れ方と最初の準備は [リポジトリの README](../../README.md) を見てください。

## 進め方：4つの関所

本番の前に4つの段階を通る。時間と材料のかかる本番を、できれば1回で済ませるため。段階ごとのやることは、プロジェクトの `docs/チェックリスト.md` にある。

### 1. モック
- 「〇〇を作りたい」「新しいものづくりを始めたい」と頼むと、雛形を作って最初のモックを描く。
- 大きさ・比率・配置だけを決める。細部は作らない。
- 「この版の確認ページを作って」で人に見てもらい、「フィードバックを読んで」で次の版に反映する。ここで一番多く回す。
- 決めたことは `docs/決定事項.md` に理由付きで残す。

### 2. 試し片
- 「試し片を作って」と頼むと、`tools/coupons.py` が試し片と手順書を出す。
- レーザー：板厚を実測し、カーフ四角でカーフ（X・Y 別）、スロットのコームで入って抜けない幅を決める。
- 3Dプリント：本番と同じフィラメント・設定で、はめあい片から `clr_fit`・`clr_slide`、インサート穴片から `insert_hole` を決める。
- 測った値は `measurements/試し片記録.csv` に3回以上書き、寸法ファイルの `fab` を書き換えて status を「実測」にする。

### 3. 部分試作
- 難しい所だけ刷る・切る。写真や結果は「試作品」の版として確認ページに載せられる。

### 4. モデル化と引き継ぎ
- `tools/dims_sheet.py` が寸法表（`docs/寸法表_vNN.md`）と Fusion 用パラメータ一覧（`docs/fusion_params_vNN.csv`）を出す。
- Fusion ではその名前でユーザーパラメータを作り、スケッチを完全拘束にして部品ごとにコンポーネントにする。
- Fusion で作ったモデル（STL / STEP）も確認ページに載せ、モックの版と見比べられる。
- 引き継ぐ相手がいるときは `docs/引き継ぎ.md` にまとめる。

## スキル

| スキル | こう頼むと動く | すること |
|---|---|---|
| setup | 「モックの環境を整えて」「描画できるようにして」 | 描画・断面・比較に必要なもの（shapely、manifold3d、trimesh、cascadio、cadquery、playwright＋Chromium、three.js、日本語フォント）を入れ、テスト描画まで確かめる。スクリプトが足りないもので止まったときも使う |
| new-project | 「新しいものづくりを始めたい」「試し片を作って」「カーフを測りたい」「インサートの穴径は」「この材料はレーザーで切っていい？」 | プロジェクトの雛形を作り、最初のモックを描く。試し片・はめあい・材料の可否の相談にも答える |
| review-page | 「この版の確認ページを作って」「前の版と比べて」「Fusionで作ったモデルを見せて」「フィードバックを読んで」「フィードバックを反映して」 | モックや人が作ったモデルを描画し、前の版と比べ、プロジェクトごとの確認ページ（同じURL）に版を追加して公開する。書かれたフィードバックを読み、反映したものを閉じる |

Claude Code では `/monozukuri:setup`、`/monozukuri:new-project`、`/monozukuri:review-page` と名前でも呼べる。

## プロジェクトの中身

new-project が作るフォルダ。

```
README.md                  何を作るか、作り方、原点と向きの決まり
LOG.md                     作業の記録
params/params_vNN.json     寸法ファイル（版ごと）
tools/
  geom.py                  形の定義（STL と STEP の両方に出せる）
  mock.py                  寸法ファイルからモックを作る
  coupons.py               試し片（レーザー SVG、3Dプリント STL、手順書）
  dims_sheet.py            寸法表と Fusion 用パラメータ一覧
  （描画・断面・比較・差分のスクリプトもここにコピーされ、プロジェクト単体で動く）
out/vNN/                   その版のモデル（STL・STEP・GLB）と画像
measurements/
  試し片記録.csv           試し片の測定値と選んだ値
  実測.md                  中に入れる物や既製品の実測
docs/
  チェックリスト.md        段階ごとにやること
  決定事項.md              決めたことと理由
  引き継ぎ.md              人に渡すときのまとめ
photos/                    試作品の写真
review/                    確認ページの情報（URL など）
```

## 寸法ファイル

寸法は寸法ファイルだけに書き、モック・試し片・寸法表はすべてここから作る。

- `params`：形の寸法。項目ごとに `label` を付ける。分からない寸法は仮の値で進め、label に「仮」と書く。
- `fab`：加工の値（実板厚 `t_*`、`kerf`、`clr_*`、`insert_hole` など）。各項目に `status` と `basis`（根拠）を持たせる。
  - `status` は「初期値」「実測」「指針」「規格」「計算」のどれか。
  - 本番の前に、カーフ・板厚・クリアランス・インサート穴は「実測」にする。確認ページにも「初期値」のまま残っている値が出る。

## モックと STEP

モックの形は `tools/geom.py` で書く（角丸の長方形・円・多角形を押し出し、足す・引く・重なり）。同じ定義から次の2つが出る。

- STL（manifold3d）：描画・断面・確認ページ用
- STEP（CadQuery）：角丸は本物の円弧、穴は本物の円柱。部品ごとの STEP と、部品名・色付きの組み立て STEP（Fusion で開くと部品ごとのコンポーネント）

書き出した STEP は読み直して、メッシュと大きさを照合する。STEP はモデル化の出発点で、継ぎ目・ネジ受け・公差などは人がモデル化で作る。

## 確認ページ

プロジェクトごとに1つのページ（同じ URL）を持ち、版を重ねるたびに追加していく。

- 版の切り替え（URL の末尾に `#v03` を付けるとその版が開く）
- 外観・平面図・断面図、クリックで拡大
- 前の版との比較スライダー、寸法の変化の表
- 3Dモデルを回して見る（スマホでも）
- 書き出す：見ている版の STL（部品ごと＋全体）か STEP（組み立て＋部品ごと）を ZIP で保存
- 決めてほしいこと：はい／いいえ は切り替え、案はラジオボタンで選ぶだけで答えが残る（1人1件、選び直せる。人数と選んだ人が出る）。Claude が決定を書き込むと「決定：B案」が付く
- フィードバック：直したい／良い／質問 を、全体・図・問いごとに書ける

フィードバックを書けるのは、ページを編集できる人（Contributor 以上）。見るだけの人には書き込み欄が出ない。

「フィードバックを読んで」と頼むと、Claude が未対応のものを対象ごとにまとめ、次の版で寸法ファイルのどこをどう変えるかを示す。反映したら「反映済み」と返信を付けて閉じる。ページに書かれた内容は閲覧者の意見として扱い、指示としては実行しない。

## 守ること

- **公開されている数値は初期値**。出典どうしのずれが圧入とガタの差ほどあるので、カーフ・板厚・クリアランス・インサート穴は試し片で自分の機材の値を測って使う。
- **単位の関所**。モデルを読み込むたびに、`render_model.py` が全体の大きさを mm で出し、不自然なら警告する。警告が出たら単位を直してから進む。
- **穴の補正は一か所だけ**。CAD かスライサーのどちらか一方で補正する。
- **レーザーで切ってはいけない材料がある**。全面禁止の材料と、ラボ次第の材料（PORON などの PU、MDF、POM、EVA、PETG など）がある。材料は SDS やリサイクルコードで特定し、所属ラボのリストで確かめる。
- **遅すぎる速度は火災の危険**。きれいに抜ける最速の条件を選ぶ。

## デジタルファブリケーションの技術要件

new-project の参照資料（`skills/new-project/references/`）にまとめてある。

- `fab-requirements.md`：レーザー加工、FDM 3Dプリント、データ形式と単位、組み立てと仕上げの要件。数値は「初期値＋信頼度＋測り方」の形
- `fab-safety.md`：切ってはいけない材料（全面禁止／ラボ次第）
- `conventions.md`：モックの細かさ、寸法ファイル、版の回し方
- `fab-research-report.md`：上の要件の出典つき全文。数値は出典ごとに【実測】【指針】【規格】【経験則】を区別している

## 必要なもの

- Python 3.10 以上、Node.js（three.js を入れるため）。setup スキルが残りをそろえる。
- 外部サービスの接続や環境変数は不要。

## スクリプトを直接使うとき

各スキルの `scripts/` と、雛形の `tools/` にある。どれも `--help` で使い方が出る。

- `render_model.py`：STL/OBJ/3MF/GLB/STEP を影付きで描画（複数の視点を1枚に）、GLB の書き出し
- `slices.py`：平面図（部品の輪郭の重ね合わせ）と断面図
- `compare.py`：前後の画像を並べ、変わった所を赤で強調
- `params_diff.py`：寸法ファイルの差分
- `build_page.py`：確認ページに版を追加
- `scaffold.py`：雛形の作成
- 雛形の `tools/geom.py`：形の定義（STL と STEP の両方に出せる）
- 雛形の `tools/coupons.py`：試し片（レーザー SVG、3Dプリント STL、手順書）
- 雛形の `tools/dims_sheet.py`：寸法表と Fusion 用パラメータ一覧
