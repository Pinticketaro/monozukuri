# monozukuri

レーザー加工・3Dプリントのものづくりで、**立体のモック → 確認ページ → フィードバック → 次の版** を速く回すための Claude プラグイン。
モックは形と比率を決めるための粗い立体で、最終形は Fusion などで人がモデル化する前提です。モデル化した結果（STL / STEP）も同じ確認ページで見比べられます。

## できること

- **setup**：描画・断面・比較・加工データに必要なもの（shapely、manifold3d、trimesh、cascadio、cadquery、ezdxf、playwright＋Chromium、three.js、日本語フォント）をまとめて入れ、テスト描画まで確かめる
- **new-project**：寸法ファイル（形の寸法＋加工の値と信頼度）、モック生成（1つの形の定義から STL と STEP。STEP は本物の円弧・円柱を持ち、Fusion で部品ごとのコンポーネントとして開ける）、試し片の生成、描画・断面・比較・寸法表のスクリプト、段階チェックリスト、引き継ぎ資料、Git 設定の雛形を作り、最初のモックを描く
- **review-page**：モックや人が作ったモデルを描画して前の版と比べ、プロジェクトごとの確認ページに版を追加して公開する。ページでは STL / STEP を ZIP で書き出せ、「決めてほしいこと」には はい／いいえ の切り替えや案のラジオボタンで答えられる。ページに書かれたフィードバックと答えを Claude が読み、反映したら返信や「決定」を付ける
- **fab-prep**：本番の手前の3つ。**製作前チェック**（材料の安全、穴と縁の距離、線の間隔、薄い壁、45°を超えるオーバーハング、5mmを超えるブリッジ、造形範囲・加工範囲などを、番号の付いた図と NG／注意／確認の表で返す）、**部分試作の切り出し**（USB の切り欠きやネジ受けの一角だけを STL・STEP・レーザー用データで）、**加工データの書き出し**（レーザーは材料・板厚ごとの SVG / DXF をカーフ補正つきで加工範囲に並べ、3Dプリントは刷る向きの 3MF）
- **machines**：機材プロファイル。造形範囲・加工範囲・ノズル径・ラボの材料の決まりと、試し片で測った値（カーフ・クリアランス・インサート穴…）を「機械×材料」ごとに残し、次のプロジェクトに適用すると最初から実測値で始まる

デジタルファブリケーションの技術要件（レーザーのカーフとはめあい、FDM のクリアランス・インサート・形の限界、データ形式と単位、パラメトリック設計と版管理、組み立てと仕上げ、レーザーで切ってはいけない材料）を、出典つきの参照資料として同梱しています。中心の考え方は「公開されている数値は初期値。試し片で自分の機材の値を測って使う」です。

詳しくは [plugins/monozukuri/README.md](plugins/monozukuri/README.md)。

## 入れ方

### Claude アプリ（デスクトップ・Web）

1. 左のサイドバーで **Customize** → **Plugins** を開く
2. **Add marketplace** を選び、`Pinticketaro/monozukuri` を入力する
3. 一覧に出た **monozukuri** を選んで **Install** を押す

マーケットプレイスを使わない場合は、[monozukuri.plugin](https://github.com/Pinticketaro/monozukuri/raw/main/dist/monozukuri.plugin) をダウンロードし、チャットに添付して追加することもできます。プラグインは有料プラン（Pro・Max・Team・Enterprise）で使えます。

### Claude Code（ターミナル）

```
/plugin install monozukuri --marketplace Pinticketaro/monozukuri
```

`/plugin` で始まるコマンドは Claude Code 専用です。Claude アプリの入力欄では使えません。

### 使い方

- **新しい会話を始めてから使う**：プラグインは会話の開始時に読み込まれます。追加する前から開いていた会話では使えません。
- **ふつうの言葉で頼む**：「モックの環境を整えて」「新しいものづくりを始めたい」「この版の確認ページを作って」「製作前にチェックして」「USB の所だけ先に刷りたい」「加工データを書き出して」「うちの Ender-3 を登録して」のように頼むと、対応するスキルが動きます。
- **名前で呼ぶ**：Claude Code では `/monozukuri:setup`、`/monozukuri:new-project`、`/monozukuri:review-page`、`/monozukuri:fab-prep`、`/monozukuri:machines` でも呼べます。
- **最初に一度だけ**「モックの環境を整えて」を実行すると、描画に必要なものがそろいます。

## 構成

```
.claude-plugin/marketplace.json   マーケットプレイスの定義
plugins/monozukuri/               プラグイン本体
  skills/setup/                   環境セットアップ
  skills/new-project/             雛形・試し片・技術要件の参照資料
  skills/review-page/             描画・比較・確認ページ・フィードバック
  skills/fab-prep/                製作前チェック・部分試作の切り出し・加工データの書き出し
  skills/machines/                機材プロファイル（測った値の記録と適用）
dist/monozukuri.plugin            Claude アプリ用のパッケージ
```

## 注意

- 技術要件の数値は、出典ごとに【実測】【指針】【規格】【経験則】を区別して載せていますが、どれも自分の機材での確認が前提です。
- レーザー加工の材料の可否はラボ（機械）ごとに異なります。所属ラボのルールを優先してください。
- 製作前チェックは形から機械的にわかることだけを見ます。はめあい・取り合いは部分試作で確かめてください。モックから書き出した加工データは形の確認用で、本番は人がモデル化したモデルから書き出す前提です。
