# monozukuri

English: [README.en.md](README.en.md)

レーザー加工・3Dプリントのものづくりで、**立体のモック → 確認ページ → フィードバック → 次の版** を速く反復するための Claude プラグイン。
モックは形と比率を決めるための粗い立体で、最終形は Fusion などで人がモデル化する前提です。モデル化した結果（STL / STEP）も同じ確認ページで見比べられます。

## 入れ方

### Claude アプリ（デスクトップ・Web）

1. 左のサイドバーで **Customize** → **Plugins** を開く
2. **Add marketplace** を選び、`Pinticketaro/monozukuri` を入力する
3. 一覧に出た **monozukuri** を選んで **Install** を押す

マーケットプレイスを使わない場合は、[monozukuri.plugin](https://github.com/Pinticketaro/monozukuri/raw/main/dist/monozukuri.plugin) をダウンロードし、チャットに添付して追加することもできます。プラグインは有料プラン（Pro・Max・Team・Enterprise）で使えます。

### Claude Code（ターミナル）

```
/plugin install monozukuri --marketplace Pinticketaro/monozukuri
```

`/plugin` で始まるコマンドは Claude Code 専用です。Claude アプリの入力欄では使えません。

## 最初に一度だけ

1. **新しい会話を始める**：プラグインは会話の開始時に読み込まれます。追加する前から開いていた会話では使えません。
2. **「モックの環境を整えて」と頼む**：レンダリングに必要なものがそろい、テストレンダリングまで確かめます。

## 使い方の流れ

ふつうの言葉で頼めば、対応するスキルが動きます。Claude Code では `/monozukuri:setup`、`/monozukuri:new-project`、`/monozukuri:review-page` と名前でも呼べます。

本番の前に4つの段階（ステージゲート）を通ります。時間と材料のかかる本番を、できれば1回で済ませるためです。

| 段階 | こう頼む | すること |
| --- | --- | --- |
| 1. モックと確認ページ | 「〇〇を作りたい」「この版の確認ページを作って」「フィードバックを読んで」 | 粗いモックで形と大きさを決める。確認ページで人に見てもらい、意見を次の版に反映する。ここで一番多く反復する |
| 2. テストピース | 「テストピースを作って」「カーフを測りたい」 | 自分の機材のカーフ・はめあい・インサート穴を、小さなテストピースで測る。測った値をパラメータファイルに戻す |
| 3. 部分試作 | 「ここだけ試したい」 | 難しい所だけ印刷する・レーザーカットする |
| 4. 本番と引き継ぎ | 「Fusion 用のパラメータを出して」 | STEP と Fusion 用パラメータ一覧で、人のモデル化に引き継ぐ |

迷ったら「次は何をすればいい？」と聞いてください。プロジェクトのチェックリストを見て案内します。

## できること（v0.5.0）

| スキル | こう頼むと動く | すること |
| --- | --- | --- |
| setup | 「モックの環境を整えて」「Mac でレンダリングできるようにして」 | レンダリング・断面・比較に必要なもの（shapely、manifold3d、trimesh、networkx、cascadio、cadquery、playwright＋Chromium、three.js、日本語フォント）をまとめて入れ、テストレンダリングまで確かめる。Mac ではプロジェクトの外の仮想環境（`~/.monozukuri/venv`）に入れる |
| new-project | 「新しいものづくりを始めたい」「テストピースを作って」「ツールを更新して」「英語にして」 | パラメータファイル（形の寸法＋加工パラメータと信頼度）、モック生成（1つの形の定義から STL と STEP。STEP は本物の円弧・円柱・円錐を持ち、Fusion で部品ごとのコンポーネントとして開ける）、テストピースの生成、レンダリング・断面・比較・寸法表のスクリプト、段階チェックリスト、引き継ぎ資料、Git 設定のテンプレートを作り、最初のモックをレンダリングする。加工方法（レーザー／3Dプリント／両方）に合わせて加工パラメータと手順を絞り、3Dプリントでサポートが要りそうな面を自動で知らせる。プロジェクトの言語（日本語／英語）を決め、切り替える |
| review-page | 「この版の確認ページを作って」「フィードバックを読んで」「ブラウザで確認ページを開いて」 | モックや人が作ったモデル（STL / OBJ / STEP）をレンダリングして前の版と比べ、プロジェクトごとの確認ページに版を追加して公開する（Claude Code では PC のブラウザで開く）。ページに書かれたフィードバックと答えを Claude が読み、反映したら返信や「決定」を付ける |

### 0.5.0 で変わったこと

- 英語に対応。言語はプロジェクトごとに日本語か英語。チャットで「英語にして」と頼んで切り替える。確認ページ・図・パラメータファイル・文書も英語になる。ページに切り替えボタンは無い
- 英語で始めたプロジェクトは英語で作られ、文書のファイル名も英語になる（`docs/checklist.md` など）
- 今までのプロジェクトは何もしなくても日本語のまま動く。英語にするときは、プラグインを更新してから「ツールを更新して」と頼む（英語の図や表示は新しいツールで出る）

### 0.4.0 で変わったこと

- 平面図に真上から見た外形が重なり、断面の高さに無いラグや突起も見える。上面・正面の図に大きな影が出ず、ビューごとに枠いっぱいにレンダリングして縮尺の目安を入れる
- テンプレート：`--process`（レーザー／3Dプリント／両方）で加工パラメータを絞る。筒・円錐台・回転体・ストラップホール付きのラグの関数。3Dプリントでサポートが要りそうな面を notes に自動で出す
- 決めてほしいことを mock の notes に問いの候補として書くと、確認ページで はい／いいえ・案の選択で答えられる。足りない情報は番号で選ぶ画面で聞く
- 確認ページを Claude Code から PC のブラウザで開ける（フィードバックは `review/feedback_local.json` に残る）。公開のたびにエクスポート（downloads）を有効にし、使えない画面では「エクスポート」を押せない表示にする
- **既存のプロジェクトは、プラグインを更新したら「ツールを更新して」と頼む**（`tools/` はプロジェクトにコピーされているため。`mock.py` は上書きせず、新しいテンプレートを `mock.py.new` として置く）

### 確認ページでできること

- 版の切り替え（URL の末尾に `#v03` を付けるとその版が開く）
- 外観・平面図・断面図、前の版との比較スライダー、寸法の変化の表
- 3Dビューでモデルを見る（スマホでも）
- 見ている版の STL / STEP を ZIP でエクスポートする
- Claude Code では PC のブラウザで開ける（「ブラウザで確認ページを開いて」）
- 「決めてほしいこと」に はい／いいえ や案の選択で答える
- フィードバック（直したい／良い／質問）を図や問いごとに書く

### 言語

- 言語はプロジェクトごとに日本語か英語です。パラメータファイルの `meta.lang` に残ります。書かれていなければ日本語です。
- 切り替えるときは、チャットで「英語にして」「日本語に戻して」と頼みます。確認ページに切り替えボタンはありません。
- 英語のプロジェクトでは、確認ページ・図の文字・寸法表・テストピースの手順書・文書が英語になります。部品名や寸法の名前は、書いたときの言葉のままです。

詳しくは [plugins/monozukuri/README.md](plugins/monozukuri/README.md)。

## 守ること

- **公開されている数値は初期値です**。カーフ・板厚・クリアランス・インサート穴は、テストピースで測った値に置き換えてから本番に進んでください。同梱の技術要件は出典ごとに【実測】【指針】【規格】【経験則】を区別していますが、どれも自分の機材での確認が前提です。
- **レーザーカットしてはいけない材料があります**。「この材料はレーザーカットしていい？」と聞けば確かめます。可否はラボ（レーザー加工機）ごとにも異なるので、所属ラボのルールを優先してください。

## monozukuri がしないこと

- 最終の製造データを自動で作ること（最終形は人が CAD でモデル化します）
- 写実的な見た目を作ること（モックは形を決めるための粗い立体です）
- 作った物を使い始めた後の保守・修理の支援

## これから

次のものを順に足していく予定です。まだ入っていません。

- 機能ごとのコマンド（`/monozukuri:help`、`mock`、`coupon`、`measure`、`review`、`feedback`、`compare`、`handoff`、`safety`）

- 図面（寸法図、組立図・部品表）
- 初学者向けに説明を増やすモードと、慣れた人向けに省くモード
- 寸法違いの派生品の一括生成、機材・材料ごとの実測値の記録
